# 单文件网页版番茄钟

一个 HTML 文件搞定的番茄工作法计时器，双击即可使用，无需安装、无需服务器、无需联网。

## 功能

- 专注 / 休息自动循环，默认 25 分钟专注 + 5 分钟休息
- 圆环进度可视化，专注与休息使用不同配色
- 自定义专注时长（1–180 分钟）与休息时长（1–60 分钟）
- 今日番茄数、今日累计专注分钟统计，按自然日自动归零
- 全部数据保存在浏览器 `localStorage`，刷新、关闭浏览器都不丢失
- 阶段结束时用 Web Audio 生成提示音，不需要额外音频文件
- 快捷键：空格开始 / 暂停，`R` 重置
- 浏览器标签页标题同步显示剩余时间
- 响应式布局，手机浏览器同样可用

## 运行

直接用浏览器打开 `index.html` 即可，或：

```bash
# Windows
start index.html

# macOS
open index.html
```

若希望以本地服务器方式运行：

```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000/index.html
```

## 使用说明

| 按钮 | 作用 |
| --- | --- |
| 开始 / 暂停 | 启动或暂停当前倒计时 |
| 重置 | 把当前阶段时间恢复到完整时长 |
| 跳过 | 立即切换到下一个阶段（不计入番茄数） |

专注阶段自然结束时，今日番茄数 +1 并自动进入休息；休息结束后自动回到专注阶段。

## 数据存储

数据保存在 `localStorage` 的 `pomodoro.state.v1` 键中，内容包含时长设置、今日番茄数、今日专注秒数与日期标记。

- 换日期后，番茄数与专注分钟自动从零开始，时长设置保留
- 清除浏览器站点数据会同时清空统计
- 浏览器隐私模式下写入可能失败，此时仅当次会话有效

## 技术说明

- 纯原生 HTML + CSS + JavaScript，无框架、无构建步骤、无外部资源
- 单个 `index.html` 文件，可离线使用
