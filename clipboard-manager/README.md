# 剪贴板历史管理器

Windows 下的轻量剪贴板历史工具，用 Python 标准库 `tkinter` 写成，不依赖任何第三方包。

## 功能

- 自动记录复制到剪贴板的所有文本内容，保留最近 300 条
- 关键词实时搜索过滤
- 双击或回车把历史条目重新复制回剪贴板
- 置顶常用内容，置顶项始终排在最前
- 单条删除、一键清空（带二次确认）
- 可暂停记录
- 历史自动持久化到 `%USERPROFILE%\.clipboard_history.json`，关闭后可恢复

## 环境要求

- Windows 系统（依赖系统剪贴板）
- Python 3.8 及以上，安装时需包含 `tkinter`（官方安装包默认包含）

## 运行

```bash
python clipboard_manager.py
```

## 使用说明

| 操作 | 方式 |
| --- | --- |
| 搜索 | 顶部输入框输入关键词，即时过滤 |
| 复制回剪贴板 | 双击条目，或选中后点「复制到剪贴板」 |
| 置顶 / 取消置顶 | 选中条目后点「置顶 / 取消」 |
| 删除单条 | 选中条目后按 Delete 键或点「删除」 |
| 清空全部 | 点「清空历史」并确认 |
| 暂停记录 | 点「暂停记录」（例如复制密码时） |

## 说明

- 程序采用轮询方式读取剪贴板，间隔 0.7 秒，对系统资源占用很低。
- 只记录文本内容，不记录图片与文件。
- 超过 10 万字符的超长文本会被跳过，避免占用内存。
- 数据保存在用户目录下的 JSON 文件，可随时手动删除。
